### 🏥 [Sepsis-LogicGraph — Clinical Data Pipeline](https://github.com/Psycoder0611/sepsis-logicgraph)

**Python · SQL · Snowflake · dbt · Neo4j · Dagster · MIMIC-IV**

**Team Project | Ingestion Lead**

A clinical data pipeline implementing Sepsis-3 detection logic and benchmarking graph-based temporal queries against Snowflake SQL.

- Contributed to the team's ingestion and data engineering workflows using MIMIC-IV clinical data.
- Worked with a Bronze–Silver–Gold Snowflake architecture, dbt transformations, Neo4j, and Dagster orchestration.
- Supported processing and analysis of approximately **19 million clinical records**.

**Independent ML Extension**

Extended the academic work into a separate machine learning investigation:

- Compared Logistic Regression, SVM, Decision Tree, Random Forest, and XGBoost.
- Achieved **0.762 ROC-AUC** and **0.878 PR-AUC** with XGBoost.
- Optimized the experimental classification threshold, achieving **97.7% recall** and reducing false negatives from 208 to 16.
